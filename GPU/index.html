What is known, and what is not

Known

  • On this Mac, long GPU compute produced repeated timeouts and desktop corruption (#2701).
  • The kernel driver enables firmware compute preemption automatically only for the M2 Max. The M2 Pro is not on that list.
  • On M2 Max, turning preemption on removed the timeouts in owners' tests.
  • There is no Metal on Linux. The graphics API here is Vulkan; Metal on macOS is the yardstick.

Not known yet

  • Whether preemption fixes the M2 Pro, and what it costs in speed.
  • How far Linux is from macOS on this chip, per workload.
  • Whether the kill-during-compute fault seen on M1 also happens here.

How it is run

Every number must come with its raw data. Anything that could hang the GPU is written down before it is tried. The research repository is private for now; findings go to Aurora Silicon first.
